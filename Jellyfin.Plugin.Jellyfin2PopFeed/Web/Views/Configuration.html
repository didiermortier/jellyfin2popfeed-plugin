Jellyfin2 PopFeed

Automatically post watched movies to PopFeed via AT Protocol.

Your Bluesky/Atmosphere handle (e.g., user.bsky.social or user.popfeed.social)
Generate an App Password in your Bluesky/Atmosphere settings (Settings > App Passwords)
Your Personal Data Server. Default: popfeed.social for Popfeed users

How it works

  1. You finish watching a movie in Jellyfin (95%+ completion)
  2. The plugin checks if that movie already exists on your PopFeed feed
  3. If it's new, it posts "Watched Movie Title (Year)" with metadata (TMDb ID, genres, release date)
  4. If it already exists, nothing happens (no duplicates)

Note: Plugin settings are global -- all users share the same PopFeed account for posting.
